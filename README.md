# 🧱 @shoplify/core - Nx Commerce Monorepo

A scalable, modular monorepo powered by [Nx](https://nx.dev), designed to build a shoplify-style commerce platform. This architecture enables clean separation of concerns, shared resources, and fast development workflows.

## 🎯 Project Goals

- 🧩 Modular and maintainable architecture using Nx
- 🖼️ Reusable, accessible UI component library
- 🔌 Shared SDK for API communication (GraphQL / REST)
- 🛠️ React-based admin panel with future-ready structure
- 🚀 Ready to scale with storefront apps or mobile integrations

## 🛠️ Tech Stack

- Nx (workspace & tooling)
- React (admin interface)
- TypeScript (type safety)
- Tailwind CSS / CSS-in-JS (UI styling)
- pnpm (fast package management)
- GraphQL / REST (API integration)
- Jest / Vitest (testing)
